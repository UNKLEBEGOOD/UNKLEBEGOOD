## Featured projects

**1. [Wellspring Clinics Performance Analysis](https://github.com/UNKLEBEGOOD/wellspring-clinics-analysis)**
Cleaned four messy tables for six clinics in Python and built a three-page Power BI dashboard on 420 visits. Found an average wait of 35.19 minutes (5.19 over target), a 45.24% follow-up rate, and ₦3.10M in revenue.
*Python, pandas, Power BI, DAX*

**2. [Medical Appointment No-Show Analysis](https://github.com/UNKLEBEGOOD/Medical-Noshow-Analysis)**
Analyzed 110,521 appointment records to find patterns in missed appointments, validated the findings in SQL Server, and built an interactive dashboard. Found an overall no-show rate of 20.2%.
*Python, SQL Server (T-SQL), Power BI*

**3. [Healthcare Claims and Billing Analysis](https://github.com/UNKLEBEGOOD/Healthcare_claims-and-billing_Analysis)**
Analyzed 70,000 billing records across 7 insurance payers to see where revenue was lost. Found a $40M gap (64.5% collection rate) driven mainly by preventable submission errors such as duplicate claims and missing prior authorizations.
*Python, SQL Server (T-SQL), Power BI*

**4. [Social Media Impact on Student Life](https://github.com/UNKLEBEGOOD/social-media-impact-analysis)** | [Live dashboard](https://social-media-impact-analysis-qscyuaiwmukxamh47hjrjn.streamlit.app)
Analyzed 4,500 student records to explore how daily social media use relates to sleep, academic performance, stress and mental health, and presented the results in an interactive dashboard.
*Python, EDA, Streamlit*

**5. [Diabetes Risk Factor Analysis](https://github.com/UNKLEBEGOOD/diabetes-risk-analysis)**
Analyzed 768 patient records to find the strongest clinical predictors of diabetes. Glucose came out as the dominant predictor (correlation 0.50), confirmed by three separate methods.
*Python, EDA, logistic regression*

**6. WHO Health Data ETL and Dashboard** *(in progress)*
Building an ETL pipeline that pulls health indicators from the WHO Global Health Observatory API, cleans them in Python, and loads them into an interactive dashboard for comparing countries.
*Python, APIs, ETL*
